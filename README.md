# GEE Task Dashboard

Simple CLI to visualize live task progress on Google Earth Engine.

## Installation

```bash
pip install git+https://github.com/fulan-m/GEE-Task-Tracker
```

## Usage

Before running for the first time, make sure you're authenticated on GEE:
```bash
earthengine authenticate
```

Run the CLI:
```bash
gee-dashboard
```
